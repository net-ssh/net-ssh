`Net::SSH.start(host, user, control_master: :auto)` runs the session through an already running OpenSSH ControlMaster (proxy mode, OpenSSH 7.4+) found via `:control_path` or ssh_config `ControlPath`, skipping connection setup, and falls back to a normal connection when there is none; ssh_config `ControlMaster` alone doesn't enable it. The master's authentication, host key and algorithm settings apply; remote port forwarding, agent/X11 forwarding and global requests raise `Net::SSH::NotSupportedOverControlMaster` and keepalive is left to the master [#443, #1057]
